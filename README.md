# AI 智能解释 & 翻译

原生 JavaScript / HTML / CSS 编写的 Manifest V3 浏览器扩展，当前版本 **v4.6.0**。在网页中选中文字即可获得流式解释或翻译，也可通过右键菜单进行全文翻译。根目录源码可直接在 Edge 中加载，无需构建或安装 npm 依赖；Markdown 解析与清理库随扩展保存在本地 `vendor/`。

## 当前功能

### 划词解释与翻译

新安装默认选中文字后自动弹出结果，也支持选中文字后右键「📖 智能解释」。扩展先在本地分类、选择当前类型的任务要求和必要材料，再发送一次生成请求；所有类型共用系统要求，不增加 AI 分类调用：

| 选中的内容 | 处理方式 |
| --- | --- |
| 外语词、短语和短片段 | 用中文先给原意译文，再解释词义或概念，按语境差异决定重点；不提供翻译例句 |
| 有句式或分句证据的外语句子、段落 | 用目标语言先给原意译文，文中含义有新增信息时才补充；不提供翻译例句；完成后可点「解释此句」；短句不再必须超过 10 词 |
| 中文词语、名称、短回应和局部片段 | 结合语境解释；支持单字，长名称不再仅按长度判为段落 |
| 有句式或分句证据的中文句段 | 解读核心含义和语境 |
| 代码、公式、表格、指标、路径、混合或不确定内容 | 使用解释连接，结合结构信息处理；不确定情况由同一次生成请求理解，不增加 AI 分类请求 |

本地规则分别判断语言、内容类别、选取位置和完整性，并保留可信度与依赖信号。位于句中的完整词语仍按词语解释；独立短应答按回应处理，句中应答词按语法关系理解；被截断的单词、指代和省略关系使用片段要求。模型收到当前类型的处理规则，分类标签与分类示例不写入任务指令。本地分类是有限规则，不是完整的语言识别器或语法分析器；实际含义仍由模型结合材料理解。

结果浮层支持 Markdown：标题、加粗/斜体、列表、引用、行内代码/代码块、表格、链接、删除线、任务列表与分隔线。流式期间约每150毫秒重新解析已收到的内容，较长文本适当降低刷新频率（最高600毫秒），完成时立即最终渲染。尚未闭合的语法可能随后续文本调整。表格和长代码行可独立横向滚动，用户向上阅读时保留滚动位置。

首次完整回答从顶部显示，流式更新保留代码块、表格和链接的键盘焦点。浮层自动检查原文选区的下方、上方和两侧，空间不足时缩小高度并在卡片内滚动，避免遮住选中文字。可在顶部标题区按住鼠标左键拖动；平时经过顶部显示普通鼠标，按下左键后显示抓取光标，松开或取消后恢复普通鼠标。标题区不显示“拖动”字样或方向/自动定位按钮。拖动后保留手动位置，流式生成、页面滚动不会移回原文，窗口缩小时会约束到可见范围。重新划词会重新自动定位。选中结果文字后仍保留原文锚点；关闭后的浮层不再参与键盘聚焦。若选区铺满视口、四周没有可用空间，则无法完全避让，可手动移动浮层；验收见 [浮层拖动与避让](docs/TOOLTIP_POSITION_QA.md)。

划词回答只输出 Markdown 正文，首段直接回答并加粗核心定义、结论或译文；出现不同解释层次时主动使用简短小标题分段，并列信息用列表，每段集中讲一个重点。提示词禁止表格、HTML、图片、图表及其他非正文输出。领域明确时优先采用该领域的通常含义；与文中用法一致时重点解释原义，合并或省略重复语境；特殊用法或含义转移时重点解释文中意思。避免机械拆词、冗余背景和固定栏目，概念难理解时可给一个简短例子；翻译不另加例句。全文翻译继续只替换译文，不向网页加入解释。

划词系统提示词要求信息足够即作答，只做最少必要思考；未知细节简短指出，不穷举猜测或反复改写相同结论，不在正文输出思考或分类过程。这是提示词引导，不是思考 token 或耗时的硬限制。2026-10-13 将 `codex/local-classified-prompts` 合入 `main`，保留 DeepSeek 官方端点显式关闭思考，其他接口沿用已有思考设置。新请求设计与验证见 [本地分类提示词验收](docs/LOCAL_CLASSIFIED_PROMPTS_QA.md)；此前回答风格记录见 [提示词风格验收](docs/PROMPT_STYLE_QA.md)。

接口返回思考内容时会按原有纯文本帧队列显示思考过程；支持复制 Markdown 原文、下载包含原文和 Markdown 回答的 TXT、点击外部或 Esc 关闭。鼠标移出或选区折叠不会自动关闭卡片。下载文件保存在浏览器下载目录的 `笔记/` 子目录。

下载按钮等待后台确认，显示“下载中…”、“已开始下载”或“下载失败，重试”；开始下载不代表文件已经保存完成，最终状态可在浏览器下载管理器中查看。目录展示名和查询时间刷新会保留已有回答缓存，更换生成语言、模型、Key或接口等配置仍使缓存失效。

模型返回的 HTML 作为文本显示，渲染结果经过标签/属性白名单清理；仅HTTP/HTTPS链接可点击，图片语法仅显示说明文字，不自动加载远程图片。当前未提供代码语法高亮、LaTeX公式或Mermaid图渲染。实现、实际Edge验收和边界见 [Markdown浮层验收](docs/MARKDOWN_RENDERING_QA.md)，本地第三方库来源及许可证见 [vendor说明](vendor/README.md)。

**网页上下文默认开启。** 按真实 Range 保存选区，优先提供所在句子，使用 `【】` 标出选区；跨块、长选区和代码等情况保留适合其结构的材料。普通完整词语不为用满预算添加相邻段落；明确的指代定义、短回应、不完整片段及代码、表格等内容可按需补充同一区域材料。相关小标题、简单表头和代码块仍可用于理解；过滤隐藏文字、导航、按钮和扩展浮层。纯汉字被实际 `lang="ja"` 声明辅助判为日文时，可发送这项语言元信息，不附带语言识别说明。超长所在句裁剪后标为句片段。

额外上下文默认预算为 **1,500 字符**，带指代、需要前文的定义或代码/表格/公式/路径等情况为 **2,500 字符**；选区自身超过 1,500 字符时缩为 800。所在句两侧、主题、结构信息及语言声明共用预算；后台对补充材料另设 3,000 字符上限，包含组装后的短选区所在句。这些是字符预算，不是精确 token。需要邻近块时最多上文 500、下文 400 字符，标题下正文可取 900，实际可因预算减少。正文不跨已识别的章节、消息或列表项边界；无可靠选区时只发送选中文字，不搜索重复词猜位置。网页地址不加入提示词。

同一文字在不同位置或上下文中可以重新请求。“解释此句”和右键触发复用已捕获的上下文，选区折叠后仍保留材料。请求由统一系统要求、当前类型的一段任务要求和 JSON 编码的选区材料组成；JSON 是发送给模型的材料格式，回答仍只允许 Markdown 正文。只有当前任务需要的材料进入请求。现行回归及边界见 [本地分类提示词验收](docs/LOCAL_CLASSIFIED_PROMPTS_QA.md)，早期分类与上下文记录见 [v4.5 修改报告](docs/SELECTION_CONTEXT_QA.md)。

当前窗口已隐藏上下文、触发方式和启用开关，但旧版保存的设置继续生效：旧版关闭过上下文，升级后仍关闭；旧版选择右键触发，升级后仍按右键触发。隐藏控件不会重置偏好。

旧版保存为停用时，设置页会显示“启用扩展”按钮；点击后恢复使用，其他偏好保留。流式连接中断后可直接重新触发同一选区；解释失败时清除结果并隐藏复制/下载，避免导出前一次译文。

### 全文翻译

在普通网页空白处右键「🌐 全文翻译」，按原有文本节点的片段替换译文。顶部工具栏可切换原文/译文或取消翻译，滚动附近内容、动态新增行内文字、文本更新及展开内容会继续处理。

批量和失败后的单条回退共用最多 50 个实际请求的队列，每批最多 8 个文本片段、合计最多 3500 字符（单个长片段单独处理）。译文按 ID 对应原文本节点，保留链接文字、强调、图片、元素引用和事件。网页自行更新后，旧响应不能覆盖新内容；取消仅恢复仍由扩展拥有的写入，节点移动也保留原文。可编辑区域、代码和保护祖先中的文本不发送；字符集不再被当作语言而误跳过翻译。工具栏进度按文本片段统计，不再向正文插入翻译指示器。

全文翻译没有提取划词所用的前后文，批量提示词使用页面标题辅助翻译。行内标签分割的句子分片翻译可能影响语序和质量；复杂网站仍需实际检查布局和恢复效果。

### 厂家与模型选择

先选厂家，再选该接口返回的文本模型，**不限制为三款**。内置 10 家官方兼容地址，另有“自定义接口”：

| 厂家 | 内置接口地址 |
| --- | --- |
| OpenAI | `https://api.openai.com/v1` |
| DeepSeek | `https://api.deepseek.com` |
| Anthropic | `https://api.anthropic.com/v1` |
| Google | `https://generativelanguage.googleapis.com/v1beta/openai` |
| 阿里千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 月之暗面 | `https://api.moonshot.cn/v1` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` |
| MiniMax | `https://api.minimax.io/v1` |
| xAI | `https://api.x.ai/v1` |
| Mistral AI | `https://api.mistral.ai/v1` |

以上是当前代码的地址预设；千问采用百炼北京接口，MiniMax 采用国际接口。其他地域、第三方网关、聚合或本机服务使用“自定义接口”。官方地址自动匹配，不在主窗口显示；自定义地址通过“配置自定义接口”弹窗填写。

自定义接口必须明确保存自己的地址。缺少、空白或非字符串地址时，设置页提示“请先配置自定义接口地址”，模型查询和解释/翻译均在请求前停止；保存 Key 不会补入 OpenAI 地址。旧 v4 配置仅有 Key、没有地址时也保留未配置状态。已保存的明确地址继续保留；如果旧版本曾自动写入 OpenAI 地址，请在“配置自定义接口”中核对是否属于你的服务。复现与回归见 [自定义接口地址验收](docs/CUSTOM_ENDPOINT_QA.md)。

模型选项来自所选连接的 `/models`，按厂家及文本用途过滤，排除明确非文本、过期和常见嵌入/图像/音频型号。过滤基于接口元数据与名称规则，不等于逐款生成能力验证。列表不加入其他厂家的型号、历史预设或公开目录猜测的调用名；自定义接口使用它返回的文本型号。完整 ID 由扩展保存并用于调用，无需手填。

每次打开窗口会自动刷新公开目录及当前已配置厂家的模型列表；切换到已配置厂家、保存 Key 或设置时，也会查询对应接口。公开目录只辅助厂家信息与展示名称，不增加模型选项，也不接收用户 Key。

刷新成功静默完成；失败在顶部显示简短红字，如“API Key 无效，请重新填写。”或“获取模型超时，请稍后重试。”。相同连接有缓存时保留已有列表；成功返回空列表则清除旧选项。更换 Key 或自定义地址后重新获取列表。短暂网络或服务端 5xx 故障最多重试一次，总时限 20 秒；后台通信无回复或断开时由设置页恢复查询。

保存新的自定义地址会同时清除使用该连接的已保存型号与模型缓存；须等待新接口列表、重新选型号并保存，失败时不会把旧型号发给新地址。保存地址不会顺带保存未确认的 Key 草稿。

### 精简设置与独立连接

设置窗口分为「📖 解释」和「🌐 全文翻译」两个标签，各自选择厂家、模型、语言及深度思考参数。自动识别的外语完整句段使用翻译标签配置，其他划词解释使用解释标签配置；不确定结构不会在生成途中切换厂家。

各厂家分别保存 API Key 和模型缓存；两个标签选择同一家时共用该厂家的连接，选择不同厂家时分别调用。API Key 保存在浏览器扩展本地存储中，保存后输入框收起，只留“重新填写 API Key”按钮；重填可取消，空输入不会清除已保存的 Key。

当前窗口不展示模型调用名、手动新增/修改/删除模型、通用设置及官方 API 地址，也没有手动刷新按钮。语言与深度思考选项继续显示。**主分支已继承关闭思考的行为：对 `api.deepseek.com` 固定发送 `thinking: { type: 'disabled' }`，不发送 `reasoning_effort`，即使保存的开关为开启也关闭思考。** 覆盖划词、解释此句及全文单条/批量，旧设置值保留；此前试用分支保留以便对照。自定义接口直接使用该官方主机也适用；第三方网关不按模型名推断支持，不添加该字段。其他接口开启时发送 `reasoning_effort`（低/中/高），关闭时省略参数、使用模型默认行为。关闭思考的原始试用记录见 [DeepSeek 关闭思考验收](docs/DEEPSEEK_THINKING_OFF_QA.md)。

## 安装与配置

需要 Edge、对应服务的 API Key，以及支持 OpenAI 格式 Chat Completions 和模型列表的接口。

2026-10-11 的 15 项问题修复通过 [PR #10](https://github.com/siwenyu1213/AI-translator-extension/pull/10) 交付到 `main`，完整证据见 [修复回归记录](docs/ADVERSARIAL_FIX_QA.md)。安装主分支版本可运行：

```bash
git clone https://github.com/siwenyu1213/AI-translator-extension.git
```

1. 打开 `edge://extensions`，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择项目根目录。
3. 打开扩展窗口，先选择模型厂家；自定义服务另需通过“配置自定义接口”保存地址。
4. 填写所选平台申请的 Key，点击“保存 API Key”，等待模型列表出现。
5. 在解释和全文翻译标签分别选择模型与语言，点击“保存设置”。
6. 在普通 HTTP/HTTPS 网页中选中文字，或右键空白处进行全文翻译。

“兼容 OpenAI”指请求协议兼容，**每家服务仍使用自己的地址和 Key**，不能用一个 OpenAI 官方 Key 调用全部厂家。当前支持 Bearer 鉴权、`GET <Base URL>/models`、`POST <Base URL>/chat/completions` 和 OpenAI 格式 SSE（`choices[0].delta.content`）。只提供 Responses API、其他原生协议或特殊鉴权的服务不在当前支持范围内。

没有 `/models` 且无已有缓存的服务，当前窗口无法新选模型；列表查询成功也不代表账号具有生成权限或模型支持全部参数。

## 更新与常见问题

更新代码后，在 `edge://extensions` 对扩展点击“重新加载”，并刷新已打开的网页。提示“扩展已重载，请刷新页面后重试”时，刷新当前网页后再划词。

- **模型列表为空或显示红字**：确认所选厂家与 Key 申请平台一致，按提示检查 Key、权限或网络。重新打开窗口会再次获取列表。
- **更换地域或使用网关**：选择“自定义接口”，填写服务提供的兼容地址。可粘贴完整 `/chat/completions` 地址，保存时自动归一化。
- **深度思考参数报错**：关闭深度思考后重试，模型需支持 `reasoning_effort`。
- **旧版升级**：保留已保存的语言、上下文和触发偏好。v3 的专用 Key 不自动发送给新接口，需重新填写；旧通用地址匹配官方预设时归入该厂家，否则保留为自定义连接。新切换的厂家需要自己的 Key。

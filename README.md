# AI 智能解释 & 翻译 - Edge 浏览器扩展

> 选中网页上的任意文本，AI 立刻在鼠标旁弹出智能解释或翻译卡片。右键空白处一键全文翻译。

这是一款轻量级 Edge 浏览器扩展。无需跳转页面、无需复制粘贴——在浏览网页时选中文字，AI 自动判断你需要解释还是翻译，即时给出分点结果。支持全文覆盖翻译（如 Edge 自带翻译）、流式打字机输出、双标签独立模型配置。

## 前置条件

- Edge 浏览器（Chrome 亦可）
- 一个支持 **OpenAI Chat Completions** 的接口地址（Base URL）及该接口的 API Key
- 选择厂家时自动填写对应的官方兼容地址；使用第三方服务、聚合网关、本机服务或其他地域接口时选择“自定义接口”手动填写
- 鉴权方式为 `Authorization: Bearer <API Key>`；这里的“兼容 OpenAI”指协议兼容，每家服务仍需使用自己的 Key

## 功能

### 智能解释（选中文本）

选中文本后右键「📖 智能解释」，扩展会在本地**自动分类**，无需手动选择模式：

| 你选中的是 | 自动做什么 | 例子 |
|-----------|-----------|------|
| 外语短词/短语（≤10词） | 先翻译再解释（释义、词性、用法、例句） | `ubiquitous` → 译文 + 解释 |
| 外语长段（>10词） | 纯翻译，完成后可点「解释此句」进一步解读 | 一段英文新闻 → 中文翻译 |
| 中文短字（≤10字） | 拓展解释（释义、背景、相关知识） | `实事求是` → 释义 + 出处 |
| 中文长段（>10字） | 结合上下文进行语境解读 | 一段评论 → 核心含义 + 深层意图 |

> **不需要在设置里切换模式。** 选中文本，点一下右键菜单，剩下的交给 AI 自动判断。

- **触发方式可选**：支持「选中自动搜索」（自动弹出）和「右键菜单搜索」两种模式
- **网页上下文**：自动提取选中文本所在段落的上下文，让结果更准确（可选开关）
- **流式输出**：所有解释/翻译结果逐 token 打字机式呈现，即时反馈
- **一键复制 / 下载**：将内容写入剪贴板或保存为 TXT 文件
- **兼容接口**：选择厂家自动填写官方 Base URL，地址只读；“自定义接口”允许手动输入。各厂家分别保存 Key 和接口模型列表，切换后恢复自己的连接。厂家由用户明确选择，后台按解释/翻译配置路由
- **厂家 → 模型两级选择**：OpenAI、DeepSeek、Anthropic、Google、阿里千问、月之暗面、智谱、MiniMax、xAI、Mistral AI 共 10 家，另有“自定义接口”。解释与全文翻译各自选择厂家和模型，可使用不同厂家的连接
- **当前接口开放模型**：保存厂家 Key 后自动查询该接口 `/models`，只显示当前厂家的文本型号，过滤其他厂家、嵌入/图像/音频等常见非对话用途及明确过期项，不限制数量。不再补入历史兼容项、其他厂家的已保存型号或公开目录猜测 ID；首次无 Key 时提示先填写 Key。自定义接口仅显示该接口返回的型号
- **打开自动刷新**：每次打开扩展窗口都无 Key 查询 OpenRouter 公开目录，不受缓存时间限制。没有手动刷新按钮，加载和成功不显示提示；失败仅在顶部显示红字“暂时无法获取模型，已保留已有列表。”，部分厂家缺失则提示部分未更新。无回复或消息通道断开时由设置页恢复刷新，恢复成功也静默。刷新不覆盖当前选择或正在输入的调用名；失败保留已有列表，重新打开即可重试
- **接口列表自动更新**：每次打开窗口、切换到已配置厂家、保存 Key 或设置时自动查询接口列表。每个厂家独立缓存，查询失败保留相同连接的已有列表；红字区分 Key 无效、权限、网络、超时和服务暂不可用。后台无回复或通信断开时由窗口按原连接恢复查询，短暂网络/5xx 故障最多重试一次，总超时 20 秒；有效空列表清除旧选项。接口返回的完整 ID 原样用于请求，查询成功不等于真实生成已通过
- **精简设置窗口**：隐藏模型调用名及新增/修改/删除入口、通用设置、官方 API 地址。原来的启用、上下文和触发方式保持已保存值；语言与思考选项仍在对应标签显示
- **Key 保存后收起**：首次填写后点击“保存 API Key”，输入框收起，只显示“重新填写 API Key”按钮；重填支持取消恢复旧值。各厂家分别保存，重新打开仍收起
- **可选思考参数**：开启后发送标准 `reasoning_effort`（低/中/高），只适用于支持此参数的接口及模型。关闭时省略参数、使用模型自身默认行为，全文翻译建议关闭

### 全文翻译（右键空白处）

在页面**空白区域右键** →「🌐 全文翻译」→ 整个页面的文本原地变为译文，保持原有布局和样式不变。滚动页面时新出现的内容也会自动翻译。

- 翻译结果直接覆盖原文（如 Edge 自带翻译效果）
- 顶部工具栏可**随时切换原文/译文**、取消翻译
- 100 并发流式输出，大幅减少等待时间
- 包含图片、链接的元素自动跳过，不会被破坏

### 双标签独立配置

设置面板分为「📖 解释」和「🌐 全文翻译」两个标签，各自拥有厂家、模型选择、思考开关和强度。比如解释使用 DeepSeek，全文翻译使用 Gemini，两端分别使用所选厂家的地址和 Key；选同一家则共用该厂家的连接配置。Key 输入状态随当前标签/厂家切换，官方地址在后台自动匹配。

## 安装

```bash
git clone https://github.com/siwenyu666-beep/AI-translator-extension.git
```

开发工作目录请保留 `.git` 文件夹与 `README.md`，以便更新代码和保存版本。分发时可以另建只包含扩展运行文件的副本。

1. 打开 Edge，地址栏输入 `edge://extensions`（或在扩展图标中点击"管理扩展"）
2. 开启左侧「开发人员模式」
3. 点击「加载解压缩的扩展」，选择克隆后的文件夹
4. 点击工具栏扩展图标，先选择厂家，再填写该厂家的“API Key”：
   - 官方兼容地址自动填写；千问默认百炼北京接口，MiniMax 默认国际接口，其他地域或第三方网关选择“自定义接口”
   - 自定义时点击“配置自定义接口”，在独立弹窗填写地址；可粘贴完整 `/chat/completions` 地址，保存时归一化
   - 点“保存 API Key”，自动查询当前接口开放模型，Key 输入框收起；以后可点击“重新填写 API Key”修改
   - 在两个标签分别选择模型，点“保存设置”；每次打开均自动刷新，失败保留对应连接缓存
   - 接口需提供兼容的 `/models` 列表；没有该接口且无已有缓存时，窗口不会猜测可用模型或提供手动调用名入口
5. 去普通网页选中文字右键，或右键空白处，即可使用

升级旧版本后请在 `edge://extensions` 点重新加载，并刷新已打开网页。v3→v4 的通用接口迁移会清空旧供应商 Key，回退到通用默认模型，保留语言、触发方式和其他自定义模型；从 v3 升级时需重新填写新接口的 Key，旧 Key 不会自动发送给新地址。v4.0→v4.1 追加厂家目录；v4.2 改为每次打开静默刷新完整文本目录；v4.3 加入厂家官方地址预设和独立 Key。原连接地址与所选厂家预设一致时归入该厂家，否则保留为“自定义接口”，保存原地址、Key 和选定模型。切换到新的厂家需填写该厂家的 Key。

支持范围为 HTTP/HTTPS、Bearer Key 鉴权、`POST <Base URL>/chat/completions`，并返回 OpenAI 格式 SSE（`choices[0].delta.content`）。只提供 Responses API、原生其他协议或需要特殊鉴权的服务不在当前支持范围内。并非一个 OpenAI 官方 Key 可用于所有服务。

## 使用技巧

- **右键菜单永远只需点一下**：选中文本 →「📖 智能解释」（自动分类，不用纠结选什么）；空白处 →「🌐 全文翻译」。没有多余的菜单项
- 已保存的触发方式、启用和网页上下文设置继续生效；v4.4 的精简窗口隐藏这些控件
- 将 Edge 默认下载目录设为你的笔记文件夹，下载的解释文件会自动归档
- 仅在接口和模型支持 `reasoning_effort` 时开启「深度思考模式」；遇到参数错误可关闭后重试
- 按【Esc】可以快速关闭弹窗

## 技术栈

- Manifest V3
- Service Worker（流式 API 代理 + SSE 解析）
- Content Script（划词检测 + 四分类自动分发 + 流式渲染 + 全文 DOM 覆盖翻译）
- OpenAI 兼容 Chat Completions API（Bearer 鉴权，stream: true）

```powershell
node scripts/verify.mjs --report artifacts/qa/static-check.json
```

静态检查通过仅说明 JavaScript 语法及已检查的本地资源引用通过；浏览器功能和真实 API 请求需按开发说明另行验收。

## 厂家目录与实时更新

公开目录仍自动更新，用于厂家信息和模型展示名称。v4.4 的下拉选项只取当前厂家接口返回的文本型号，公开目录不会增加选项；缓存也按厂家隔离。列表不保证模型支持全部 Chat Completions 参数或账号具有生成权限，仍需真实生成验收。

DeepSeek 的型号与显示名按 [官方模型列表接口](https://api-docs.deepseek.com/api/list-models/) 返回；历史兼容项不再额外显示。自定义网关保留其返回的精确 ID，模型调用名不在设置页展示。

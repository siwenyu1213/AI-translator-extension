# 说文 · LingoClarify

**网页划词翻译、语境解释与全文翻译。**

AI Translation & Contextual Explanation for the Web

说文是一款使用自备 API Key 的 Manifest V3 浏览器扩展。选中网页上的词语、句子或其他内容，即可在当前页面查看流式回答；也可以翻译整页并随时切回原文。

当前版本：**4.6.0**。源码可直接在 Edge 中加载，无需构建或安装 npm 依赖。

## 能做什么

- **划词翻译与解读**：解释词义、概念、句意和语境，也能处理代码、公式、表格中的选区及不完整片段。
- **全文翻译**：处理视口附近及滚动出现的文字，继续响应动态新增、更新或展开的内容，支持原文/译文切换与取消。
- **流式 Markdown 浮层**：正文逐步显示，支持标题、强调、列表、引用和代码等排版；可按住顶部拖动。
- **复制与笔记下载**：复制回答的 Markdown 原文，或下载包含所选原文和回答的 TXT。
- **解释与翻译分别配置**：两个用途可选择不同厂家、模型和语言；各厂家保存自己的 Key 和模型列表。
- **自定义接口**：可连接满足兼容协议的第三方网关、聚合服务或本机服务。

## 安装与首次配置

需要 Edge、所选服务的 API Key，以及兼容的模型列表与流式生成接口。扩展本身不提供免费模型额度；调用费用和权限由所选服务决定。

克隆仓库：

```bash
git clone https://github.com/siwenyu1213/LingoClarify.git
```

也可以在 GitHub 点击 **Code → Download ZIP**，解压后使用包含 `manifest.json` 的文件夹。

1. 打开 `edge://extensions`，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择包含 `manifest.json` 的项目根目录。
3. 点击“说文 · LingoClarify”图标，进入设置窗口。
4. 在“解释”标签选择模型厂家。使用自定义服务时，先通过“配置自定义接口”保存地址。
5. 填写该服务的 Key，点击“保存 API Key”，等待模型列表加载，再选择模型和解释语言。
6. 在“全文翻译”标签配置翻译用途的厂家、模型与目标语言，然后点击“保存设置”。
7. 打开普通 HTTP/HTTPS 网页，选中文字开始使用。

## 怎么使用

### 划词翻译与解释

默认选中文字后自动弹出回答，也可以选中文字后右键选择 **“📖 说文：解释选中文字”**。

| 选中的内容 | 处理方式 |
| --- | --- |
| 外语词语、短语和短片段 | 先给中文含义或译文，再解释词义、概念及必要的语境差异 |
| 外语完整句子或段落 | 使用翻译配置给出目标语言译文，必要时补充文中含义；完成后可点“解释此句” |
| 中文词语、名称或句段 | 解释概念、整体意思及关键关系 |
| 代码、公式、指标、表格或不完整片段 | 使用解释配置，结合选区结构与必要材料处理 |

扩展先在本地判断选区类型，再发送一次生成请求。分类规则不是完整语言识别器，实际解释质量仍取决于模型和提供的材料。

浮层会尝试避开原文选区，空间不足时限制高度并在内部滚动。**在顶部按住鼠标左键即可拖动**，按下时显示抓取光标，松开后恢复。拖动后的位置在流式更新和页面滚动时保留；重新划词会重新自动定位。点击浮层外部、关闭按钮或按 Esc 可关闭。

![说文划词结果浮层](docs/materials/screenshots/result.png)

截图中的回答由本机模拟接口提供，仅演示界面与 Markdown 排版，不代表真实模型效果。

回答优先给出核心译文、定义或结论，必要时用小标题和列表组织解释。概念可配简短例子，翻译不额外生成例句。实际格式由模型决定。

浮层支持 Markdown 标题、加粗、斜体、列表、引用、代码、表格、链接等显示；表格与长代码可独立横向滚动。复制保留 Markdown 原文。下载文件位于浏览器下载目录的 `笔记/说文_时间戳.txt`；“已开始下载”表示浏览器已接受任务，最终保存状态以下载管理器为准。

### 全文翻译

在普通网页空白处右键选择 **“🌐 说文：全文翻译”**。

顶部工具栏显示进度，可切换原文/译文或取消。译文按原有文本节点写入，保留链接、图片、强调结构及元素引用；滚动附近的内容和动态文字会继续处理。取消时恢复仍由扩展写入的文字，尽量保留网页自身的更新。

复杂页面和行内标签切分的句子仍可能影响翻译质量或布局。可编辑区域、代码及标记为禁止翻译的区域不会作为全文任务发送。全文翻译只写入译文，不附加解释。

## 厂家、模型与接口

设置页内置 **OpenAI、DeepSeek、Anthropic、Google、阿里千问、月之暗面、智谱、MiniMax、xAI、Mistral AI** 的地址预设，另有“自定义接口”。

预设用于地址选择，**不等于每家原生协议或每款模型都已验证兼容**。所选服务必须支持下列请求；只提供其他原生协议的服务需要兼容网关。

| 用途 | 当前协议要求 |
| --- | --- |
| 鉴权 | `Authorization: Bearer <API Key>` |
| 模型列表 | `GET <Base URL>/models`，返回兼容的 `data` 列表 |
| 生成 | `POST <Base URL>/chat/completions` |
| 流式正文 | OpenAI 格式 SSE，正文位于 `choices[0].delta.content` |

模型选项来自所选接口返回的文本型号，完整模型 ID 自动保存。每次打开设置页、切换已配置厂家或保存配置时会查询列表；成功静默更新，失败显示具体提示。同一连接的已有列表可在查询失败时保留。

两个标签选择同一家时共用该厂家的连接；选择不同厂家时分别使用各自的 Key。不同厂家不能共用一个 OpenAI 官方 Key。

自定义接口必须保存自己的地址。支持填写 Base URL，也支持粘贴完整 `/chat/completions` 地址并自动归一化；缺少地址时不发送请求。修改自定义地址后，需要等待新列表、重新选择模型并保存。其他地域或不同网关同样使用自定义接口。

解释语言提供中文、英文和自动选项；外语词语的翻译加解释固定以中文输出。翻译目标语言提供中、英、日、韩、法、德、西、葡、俄、阿拉伯语。

**DeepSeek 官方主机 `api.deepseek.com` 固定关闭思考**，覆盖划词、再次解释和全文翻译，设置中的思考开关对此主机不生效。其他接口开启思考时发送 `reasoning_effort`；关闭时省略该参数，采用模型默认行为。第三方网关是否支持思考参数取决于服务自身。

当前不支持仅有 Responses API 的服务或特殊鉴权协议。没有兼容模型列表、且没有可用缓存时，无法在设置页新选模型；列表查询成功也不保证生成权限。

## 数据与隐私

- API Key 和设置保存在浏览器扩展的 `chrome.storage.local` 中；保存 Key 后输入框收起，可重新填写或取消编辑。
- 划词默认结合所在句、必要的邻近文字和结构信息。这些材料与选中文字一起发送到你选择的模型服务；全文翻译发送待翻译文字，批量任务可使用页面标题。网页地址不加入生成提示词。
- 公开模型目录用于辅助显示厂家和型号名称，刷新时不发送你的 Key 或网页内容。
- Markdown 解析与清理由扩展随附的本地库完成。远程图片不会自动加载，HTML 不作为网页代码执行，只有 HTTP/HTTPS 链接可点击。
- 扩展没有提供对话云同步或开发者托管的生成服务；模型服务的数据处理规则由该服务决定。

## 更新与常见问题

更新源码后，在 `edge://extensions` 点击“重新加载”，并刷新已打开的网页。

| 情况 | 处理方法 |
| --- | --- |
| 提示扩展已重载 | 刷新当前网页后重新划词 |
| 模型列表为空、Key 无效或查询超时 | 核对所选厂家、Key、账号权限与网络；确认服务提供兼容的 `/models` |
| 自定义接口提示缺少地址 | 打开“配置自定义接口”，保存服务商给出的地址 |
| 模型不支持思考参数 | 关闭该用途的深度思考后重试 |
| 设置页显示“扩展当前已停用” | 点击“启用扩展”，然后刷新网页 |
| 浮层仍挡住原文 | 按住顶部拖到其他位置；选区占满视口时无法保证完全避让 |
| 下载失败 | 点击下载按钮重试，并检查浏览器下载管理器 |

内容脚本不能在浏览器内部页面、扩展商店等受限制页面运行。当前没有代码语法高亮、LaTeX 公式或 Mermaid 图渲染。

## 开发与验证

项目使用原生 JavaScript、HTML、CSS。根目录是扩展运行文件；本地第三方库位于 `vendor/`，验证工具位于 `scripts/`。

```powershell
node scripts/verify.mjs --report artifacts/qa/static-check.json
node scripts/verify-api.mjs
git diff --check
```

静态检查和后台模拟不能替代浏览器交互或真实模型验收。实际 Edge 验证使用本机已有 Playwright、隔离配置和合成接口；各厂家真实生成、模型质量与耗时需要有效凭据另行确认。
